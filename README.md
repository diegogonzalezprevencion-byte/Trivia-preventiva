# Trivia de la Movilidad — Supabase

Versión corregida para GitHub y Vercel.

## Corrección aplicada

Supabase se instala mediante npm y queda incluido dentro de la compilación de Vite. La aplicación ya no depende de cargar la biblioteca desde un CDN externo antes de activar las pestañas de acceso.

## Publicación

1. Subir todos los archivos de esta carpeta a la raíz del repositorio de GitHub, reemplazando la versión anterior.
2. Hacer Commit changes.
3. Vercel detectará Vite, instalará las dependencias y ejecutará `npm run build`.

No se requiere ejecutar nuevamente código SQL en Supabase.
