# Trivia de la Movilidad — Supabase

Versión estática para GitHub y Vercel.

Archivos requeridos en la raíz del repositorio:
- index.html
- styles.css
- app.js
- supabase-lite.js
- supabase-config.js
- vercel.json

No requiere package.json, npm, Vite ni configuración adicional de Node.js.


## Ajuste requerido en Supabase

Para que las personas ingresen inmediatamente después de registrarse, desactiva **Confirm email** en Authentication → Sign In / Providers → Email.
