# Trivia de la Movilidad — versión estática con Supabase

Esta versión no usa npm, Vite ni Node.js. Los archivos se publican directamente en Vercel y la conexión con Supabase está implementada localmente.

## Publicación

Sube todos los archivos directamente a la raíz del repositorio de GitHub y reemplaza las versiones anteriores. Si existen `package.json`, `package-lock.json` o una carpeta `node_modules`, elimínalos del repositorio.

Vercel debe detectar el proyecto como **Other** y publicarlo sin etapa de compilación.
